# 🌳 Terraria Quiz ⚔️

Um quiz interativo desenvolvido com HTML5, CSS3 e JavaScript puro para testar seus conhecimentos sobre o universo de **Terraria** (bosses, itens, NPCs e mecânicas do Hardmode).

## 🚀 Como jogar online
Ative o **GitHub Pages** nas configurações deste repositório (`Settings > Pages > Branch: main`) para gerar o link jogável direto no navegador.

## 🛠️ Tecnologias usadas
- HTML5
- CSS3
- JavaScript (Vanilla JS)
